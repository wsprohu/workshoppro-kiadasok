# WorkShopPro – telepítők és frissítések

A **WorkShopPro** autószerelő műhelyeknek készült szervizprogram (VidaSOFT).

Ez a tároló csak a kész Windows-telepítőket és az online frissítéshez szükséges adatokat tartalmazza.

## Telepítés

1. Nyisd meg a [legújabb kiadást](../../releases/latest).
2. Töltsd le a `WorkShopPro_x.y.z_x64-setup.exe` fájlt, és futtasd.

A már telepített program a **Beállítások → Frissítés** menüpontban magától megtalálja az új verziókat.
